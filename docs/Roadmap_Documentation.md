# Roadmap de construcción

## Entrega 0: Fundaciones

Identidad, consentimiento, sistema de diseño, API base, CI/CD, observabilidad, modelo de datos y seguridad transversal.

## Entrega 1: Producto personal

Perfil, catálogo de ejercicios, planes curados, creador manual, ejecución de sesiones, progreso básico y sincronización móvil.

## Entrega 2: IA y Premium

AI Gateway, generador guiado, coach contextual, análisis de evolución, suscripciones Apple/Google y límites de uso.

## Entrega 3: Operación de gimnasios

Organizaciones, sedes, roles, socios, membresías, invitaciones, QR dinámico, panel web y app operativa.

## Entrega 4: Cobros, reportes y endurecimiento

Pagos manuales/digitales, conciliación, reportes, auditoría, pruebas end-to-end, revisión de seguridad y preparación legal/operativa para Colombia.

## Criterio de lanzamiento

Se publica solo cuando cada entrega integrada cumple sus escenarios de QA, las políticas legales están revisadas, pagos y QR se prueban en staging con proveedores reales, y existe un plan de soporte e incidentes.
